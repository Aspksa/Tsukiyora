# Tsukiyora — Цукиёра

Первый технический этап: локальный Python-сервер загружает профиль личности из `soul/personality.json` и показывает его в браузере. Это **ещё не чат и не подключённая облачная нейросеть**.

## Windows — запуск одним BAT

1. Скачайте **ветку `feat/soul-core-personality`**, распакуйте в любую папку (включая внешний SSD и русские пути).
2. Убедитесь, что установлен Python 3.10+ (Python Launcher `py` или `python` в PATH).
3. Дважды щёлкните `Tsukiyora.bat`. Должна открыться страница на `127.0.0.1`.
4. Чтобы остановить сервер — нажмите `Ctrl+C` в консоли или закройте её.

BAT ищет рабочую версию Python; Python проверяет профиль, защищает от второго запуска из той же папки, выбирает свободный локальный порт (начиная с 53554), ведёт ротируемый журнал в `runtime/launcher.log` и пытается открыть браузер.

## Для диагностики

```powershell
python launcher.py --check
python launcher.py --no-browser --port 53554
python -m unittest discover -s tests -v
```

Маршруты: `/` — страница; `/api/health` — состояние; `/api/personality` — только публичные поля профиля. `POST` возвращает 501, пока облачная модель и чат не настроены. Никакие секреты и приватные воспоминания не должны попадать в GitHub. Локальные `runtime/`, `data/` и `.env` исключены из Git.

## Архитектура и границы этого этапа

- Python — единственный локальный API-сервер; сторонних Python-пакетов нет.
- SQLite, облачный API и интерактивный чат будут подключены отдельными этапами.
- TypeScript + HTML5 Canvas + CSS и Node.js для сборки UI остаются утверждённым целевым стеком; пока страницу генерирует Python без JS-интерфейса.
- `main` не изменена: работа идёт в ветке `feat/soul-core-personality`.

Описание характера: [`docs/SOUL_CORE_PERSONALITY.md`](docs/SOUL_CORE_PERSONALITY.md).
