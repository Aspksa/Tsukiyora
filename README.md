# Цукиёра · Tsukiyora

Локальная кицунэ-помощница с собственным профилем личности, памятью SQLite и лаконичным чёрно-золотым интерфейсом.

**Стек:** Python 3.10+ (локальный API), SQLite, HTML5 Canvas + CSS, JavaScript-совместимый TypeScript. Без Docker, Ollama и дополнительных Python-библиотек.

## Запуск на Windows

1. Скачайте ZIP из нужной ветки репозитория и распакуйте на компьютер или внешний SSD.
2. Убедитесь, что Python 3.10+ установлен (или подготовлен `runtime/python/python.exe`).
3. Запустите `Tsukiyora.bat` двойным щелчком. В браузере откроется локальный адрес `127.0.0.1` со свободным портом.
4. Откройте значок настроек → «Воспоминания» для добавления и поиска записей. Всё сохраняется в `data/tsukiyora.sqlite3`.

Для остановки закройте окно запуска. Двойной запуск не создаёт второй сервер.

## Возможности

- Утверждённый характер из `soul/personality.json`: верность, тепло, самостоятельность и честность.
- Локальный Python API с автоматическим выбором порта и проверкой состояния.
- SQLite-память: факты, предпочтения, события, биография; поиск, защита от повторов, исправление с историей.
- Хранение истории диалогов в SQLite через API для будущего подключения облачной модели.
- Резервная копия памяти по кнопке внутри настроек (`data/backups/`).
- Лаконичный экран с Canvas и минимальным числом настроек.

**Пока не работает:** общение с облачной моделью и отправка сообщений в чате, голос, автоизвлечение фактов, векторный поиск, SOUL ACADEMY. Никаких выдуманных ответов или воспоминаний на экране нет.

## Тесты

```powershell
python -m unittest discover -s tests -v
```

Тесты для Windows и Linux запускаются в GitHub Actions на pull request. Реальный запуск и внешний вид на пользовательском компьютере проверяются отдельно.
