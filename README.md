# Цукиёра · Tsukiyora 🦊

## Tsukiyora 10.0 — Unified Cognitive Life Cycle

Общение, память, личность, обучение и автономный контроль теперь имеют
**единый слой координации** без дублирования таблиц или нового фонового
процесса. Обычный и потоковый чат используют один ограниченный контекст
с реальными ID сообщений. По разрешённому уровню автономности
запускается **одна локальная задача аудита V10** через прежнюю SQLite-очередь;
результат сохраняется раз в день в существующий журнал V8.

В настройках появился единый центр **«Tsukiyora 10.0»**: источники данных,
счётчики реальных отзывов, учебные и памятные предупреждения и переходы
к прежним настройкам ручного одобрения. Автопереписывание личности и
памяти, самовольная активация навыков и дополнительные обращения к Cloud.ru
запрещены. Длинный контекст в обычном пользовательском запросе всё ещё
может потреблять токены.

[Реализация, ограничения и проверки](docs/UNIFIED_LIFE_CYCLE_10.md).

## Выбранные улучшения 2, 3, 4, 5 — контекст и доказательное развитие

В обычном и потоковом чате добавлен ограниченный локальный поиск
релевантных старых пользовательских сообщений по всей истории с реальными
ID источников (FTS5, без дополнительных Cloud.ru-вызовов). Ручные
контрольные сравнения навыков теперь показаны отдельно от фактических
оценок сохранённых ответов: оценки пользователя **не доказывают**
независимого роста качества LLM.

Инициатива учитывает тему последней беседы, не показывается по посторонней
теме или одновременно с карточкой V8. В настройках доступна
**«Результаты развития»** — обзор реальной памяти, отзывов, контрольных
заданий, целей и предупреждений очереди. Всё локально и только для чтения,
без изменения личности и порогов ручного одобрения навыков.

[Подробные механизмы и ограничения](docs/QUALITY_SELECTED_2_3_4_5.md).

## Living Dialogue 9.0 — выбранные функции 1, 2, 5, 11, 12, 13

Естественное и доброжелательное общение, честное аргументированное мнение,
контекст длинной беседы с **реальными ID старых сообщений**, возвращение
к фактической сохранённой истории и ненавязчивая инициатива по существующим

которое можно отложить на сутки. Данные разных разговоров не смешиваются.

Новых самостоятельных вызовов Cloud.ru нет, но размер промпта обычного
чата может немного меняться. Персонаж, исходная память, SQLite-очередь,
согласования навыков и структура папок сохранены.
[Подробности и ограничения выбранных шести улучшений](docs/COGNITIVE_SOUL_90_SELECTED.md).

## Cognitive Soul 8.0 — личность и безопасная самостоятельность

Единый локальный цикл развития: постановка целей по существующим
источникам V1–V7, три контрольных шага с сохранением прогресса,
исследовательские вопросы, дневник опыта, отзывы о характере и
предложения прямо в чате.

Выбран уровень **3 — расширенная безопасная локальная автономность**.
Это не разрешает переписывать исходную личность, изменять подтверждённую
память, активировать новые навыки, выполнять внешние действия или
расходовать Cloud.ru. Новые разрешения только для локальных операций;
локальный поиск по уже индексированным документам и только одобренным
исследовательским вопросам отключён по умолчанию. Существующий лимит
Cloud.ru Skill Forge 6.0 не изменён.

[20 функций, права, ограничения и API](docs/COGNITIVE_SOUL_80.md).

## Cognitive Soul 7.0 — объединение и проверяемое развитие

Единый реестр существующих навыков V1–V6, локальный план проверки, SQLite-диагностика и защита от автоматической активации недостаточно проверенных новых навыков. **Минимум 8 уникальных пользовательских парных контрольных примеров, прирост на 2 правильных ответа, 0 регрессий и явное одобрение**. Эти сравнения основаны на подтверждённых данных пользователя, а не независимых запросах к Cloud.ru.

Новые фоновые задания работают в прежней SQLite-очереди. Ранее разрешённые лимиты Cloud.ru не увеличены, новые платные испытания не выполняются. [Все 20 пунктов и ограничения](docs/COGNITIVE_SOUL_70.md).

Локальная кицунэ-помощница с характером, чатом Cloud.ru, долговременной памятью и историей развития. Чёрно-золотой минималистичный интерфейс: ядро слева, чат справа, всё остальное внутри одной кнопки настроек.

## Skill Forge: простое ВКЛ/ВЫКЛ + предложения в чате

В Cognitive Soul 6.0 и в заголовке чата появился один переключатель
**«Cloud.ru самообучение: ВКЛ/ВЫКЛ»**.
По умолчанию ВЫКЛ; включение с явным предупреждением разрешает
**максимум 1 потенциально платный запрос Cloud.ru в сутки** на новый
неисполняемый черновик навыка. Это ограничение количества, **а не денег**:
стоимость токенов нужно проверять по тарифу Cloud.ru. Выключение
запрещает новые автоматические обращения, но не отменяет уже отправленный
запрос и не сбрасывает дневной счётчик.

Цукиёра показывает прошедшие **локальную структурную проверку**
черновики прямо в чате с кнопками **«Применить навык»** и **«Отклонить»**.
Реальные ответы LLM этим тестом не проверяются; ни один навык
самостоятельно не активируется. Несколько обычных оценок «♡» тоже
могут породить кандидата без обязательного письменного комментария.

## Cognitive Soul 6.0 — Autonomous Skill Forge

Новая встроенная библиотека неисполняемых навыков, интегрированная в
**одну существующую очередь SQLite версии 5.0**. Автоматически из
повторяющихся подтверждённых положительных оценок создаёт **черновики**,
объединяет локально проверенные методы, предлагает новые версии после
ошибок и анализирует пробелы навыков. Локально проверяет структуру и
сохраняет источник, версию, перенос между областями, историю результатов,
оценки, конкуренцию и безопасный откат.

**Ни один новый навык не применяется без ручного одобрения.**
Локальные проверки не доказывают рост реального интеллекта:
они проверяют порядок разрешённых шагов, а не фактические ответы LLM.

**Cloud.ru по умолчанию полностью заблокирован для Skill Forge.**
Будущий вызов потребует отдельного согласования числа запросов/бюджета,
а затем дополнительного подтверждения каждого платного обращения.
Без новых зависимостей, Docker/Ollama, изменений личности и памяти.

Настройки → Опыт и биография → **Cognitive Soul 6.0**.
[Полные 15 возможностей, ограничения, API](docs/COGNITIVE_SOUL_60.md).

## Запуск

1. Откройте главную ветку проекта в GitHub → **Code → Download ZIP**.
2. Распакуйте на Windows-ПК или внешний SSD. Нужен Python 3.10+ либо подготовленный `runtime/python/python.exe`.
3. Дважды щёлкните `Tsukiyora.bat`. Откроется локальная страница на `127.0.0.1` со свободным портом.
4. В настройках → Cloud.ru введите ключ Foundation Models, загрузите модели, выберите модель и нажмите **«Проверить Cloud.ru»**. Проверка обращается к реальному каталогу моделей, обычному чату, SSE-потоку и (если выбрана) embedding-модели. Все запросы могут расходовать токены.
5. Теперь можно писать в чат: ответы приходят по частям, кнопку **■** можно использовать для остановки. Диалоги сохраняются в SQLite.

Ключ **не сохраняется на диск** и вводится повторно после нового запуска. Личные файлы и база SQLite остаются внутри `data/`, которая исключена из Git.

## Функции

- **Cloud.ru:** отдельный ручной live-чек каталога, обычного ответа, SSE и эмбеддингов; выбор моделей, потоковый чат и отмена.
- **Память:** факты, предпочтения, события, биография; источники, история корректировок, удаление, резервные копии.
- **Предложения памяти:** обнаружение некоторых явных фактов в разговорах и сохранение **только после подтверждения**.
- **RAG:** гибридный поиск, SQLite-кэш реальных эмбеддингов (индексация только по согласию), локальное объединение текстовых, графовых и закэшированных векторных результатов без скрытого платного переранжирования.
- **Связи:** поиск похожих записей, потенциальных противоречий и смысловых дублей по уже закэшированным векторам, с указанием источников. Никаких автоудалений.
- **Развитие личности:** биография, история взаимодействий, безопасные учебные цели по оценкам пользователя, программная модель тона, локальный фоновой цикл и журнал прогресса. Защищённый характер не переписывается.
- **Живая карта:** до 2400 реальных сот памяти, восемь секторов, адаптивные кластеры при отдалении, реальные связи, масштабирование, перетаскивание и переход к записи.
- **v0.7 — многоуровневая память:** краткосрочные сообщения, подтверждённые эпизоды, семантические факты и биография, с источниками, версиями и приоритетами.
- **v0.7 — проверка источников и SOUL ACADEMY:** отслеживание ссылок на воспоминания, осторожные выводы об ошибках, безопасные учебные цели по явным оценкам.
- **v0.7 — надёжность:** очередь локального обслуживания с приоритетом чата, автоматическая проверенная копия SQLite примерно каждые 5 часов, отдельное офлайн-восстановление и локальная диагностика без облачного ключа.
- **v0.8 — точная память:** локальный SQLite FTS5/лексический поиск, автоматическое восстановление поискового индекса, объяснимые оценки релевантности, ссылки на источники и связанные факты.
- **v0.8 — SOUL ACADEMY 2.0:** учебные циклы по явным оценкам, перенос безопасных стратегий между диалогами и возможность отключения; без переобучения облачной модели.
- **v0.8 — глубокая личность:** устойчивые подтверждённые привычки общения, биографическая и диалоговая история без выдуманных эмоций или переписывания защищённого характера.
- **v0.8 — новый мозг:** для больших баз серверная карта с 8 секторами, кластерами по 256 записей и сотами по запросу; выдерживает десятки тысяч записей без передачи всех узлов в браузер.
- **v0.8 — сохранность:** дополнительная проверка резервных копий, самодиагностика интерфейса и разграничение локальных и реальных облачных проверок.
- **v0.9 — стабилизация:** `Tsukiyora.bat --self-test` проверяет запуск с временной SQLite, не открывая браузер и не трогая личную память; CI Windows/Linux.
- **v0.9 — RAG:** локальный многопроходный поиск FTS5 + граф, ссылки на источники, сигналы возможных противоречий и устаревания.
- **v0.9 — SOUL ACADEMY 3.0:** сравнение явных оценок пользователя в контрольных окнах, измеримый прогресс и стабильные стратегии без изменения кода.
- **v0.9 — биография:** датированная хронология подтверждённых фактов и истории общения с источниками.
- **v0.9 — мозг 100 000+:** добавлен уровень областей 8192 ID перед 256-ID кластерами, с ограниченной загрузкой на экран.
- **v0.9 — защита SQLite:** предмиграционные копии, версия схемы, аудит целостности и безопасная пробная реставрация во временную базу.
- **v1.0 — RAG 4.0:** локальное слияние FTS5, графа и ранее сохранённых эмбеддингов, с указанием источников и уровня подтверждения; без скрытого платного rerank.
- **v1.0 — SOUL ACADEMY 4.0:** два фиксированных формата ответа в стабильных экспериментах, сравнение явных оценок с оговоркой о недостаточности данных.
- **v1.0 — карта:** переход к памяти по ID, многоуровневые кластеры и адаптивная частота Canvas. Нет загрузки миллиона узлов в браузер.
- **v1.0 — защита:** транзакционные лимиты запросов Cloud.ru, категории ошибок без секретов и сериализация автоматических/ручных резервных копий.
- **v1.0 — интерфейс:** улучшенная чёрно-золотая типографика и доступные раскрывающиеся настройки, без новых страниц и зависимостей.
- **v1.1 — RAG 5.0 и документы:** пользовательский импорт TXT/Markdown в локальную SQLite, цитаты реальных фрагментов, проверка ссылок и предупреждения о противоречиях; в Cloud.ru документ попадает только после отдельного согласия на текущий сеанс.
- **v1.1 — SOUL ACADEMY 5.0:** измеримые цели, выявление регрессий по оценкам, контроль ограниченных экспериментов без переписывания кода или весов модели.
- **v1.1 — развитие характера:** история версий подтверждённых привычек и биографии, защищённый профиль остаётся неизменным.
- **v1.1 — миллион воспоминаний:** CI создаёт миллион реальных строк памяти в тестовой SQLite, проверяет ограниченную загрузку и пагинацию; FPS пользовательского браузера не считается доказанным.
- **v1.1 — фоновое обслуживание:** расширены локальные задачи качества, документов, обучения и характера с приоритетом чата. Работают только пока запущен сервер.
- **Дополнение v1.1 поверх v1.2 — история диалогов PRO:** локальный FTS5-поиск по всем сохранённым сообщениям, источниковые выдержки-сводки длинных бесед и быстрый переход к старому диалогу.
- **Дополнение v1.1 поверх v1.2 — семантическая память:** явно подтверждаемые и обратимые связи похожих фактов без удаления исходных записей, с проверкой устаревших связей после исправления.
- **v1.2 — RAG 6.0:** по явному согласию добавлен локальный импорт DOCX и простых текстовых PDF без внешних библиотек; датированные/денежные формулировки и условия договоров привязаны к цитатам. OCR и сложные PDF не поддерживаются.
- **v1.2 — SOUL ACADEMY 6.0:** четыре контрольных вопроса, локальные эвристические проверки и обратимый откат необязательных стилей при неудачных явных оценках.
- **v1.2 — личность:** отображение только реально существующих связей между подтверждёнными биографическими воспоминаниями и событиями.
- **v1.2 — мозг PRO:** материализованные SQLite-счётчики с триггерами, проверка/перестройка агрегатов, миллионный нагрузочный тест на Windows/Linux.
- **v1.2 — память без потерь:** SHA‑256 новых резервных копий, проверка контрольной суммы перед репетицией восстановления, пассивная диагностика WAL.
- **v1.2 — SOUL NEXUS:** более чёрный фон, золотое свечение реальных событий, виртуализированные соты и компактные настройки; никаких демонстрационных нейронов.

На экране нет множества вкладок: поиск, предложения памяти, история развития и настройки подключения компактно находятся в существующем диалоге настроек.

## Что пока требует дальнейшей работы

Гарантированно безошибочное определение противоречий, обучение весов облачной LLM, полноценное обучение на документах, голосовой движок и автономные агенты. Эвристика автоматических предложений может пропускать факты. Развитие характера — программная модель и журнал, а не подтверждённое сознание.

**Живую работу Cloud.ru** можно подтвердить только на компьютере с твоим ключом и действующей моделью; GitHub Actions использует имитацию ответов сервиса.

## Тесты

```powershell
python -m unittest discover -s tests -v
```

GitHub Actions запускает тесты на Windows и Linux, проверяет синтаксис Python и JS, BAT-запуск, память, поток SSE, отмену и безопасность запросов. Визуальный запуск на личном компьютере проверяется отдельно.
