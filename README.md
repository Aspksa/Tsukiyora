# Tsukiyora · Цукиёра

Переносимая локальная Цукиёра: Python-сервер, SQLite, ядро личности и минималистичный браузерный экран.

**Текущая рабочая ветка:** `feat/soul-core-runtime`. Основная `main` намеренно не менялась.

## Первый запуск на Windows
1. [Откройте рабочую ветку](https://github.com/Aspksa/Tsukiyora/tree/feat/soul-core-runtime).
2. Нажмите **Code → Download ZIP**, распакуйте в папку на компьютере или внешнем SSD.
3. Установите Python 3.10+ или подготовьте `runtime/python/python.exe`.
4. Дважды нажмите **Tsukiyora.bat**. Откроется локальная страница Цукиёры в браузере.

Ни Docker, ни Ollama, ни отдельный платный сервер, ни дополнительные Python-библиотеки на этом этапе не требуются.

## Что работает
- Локальный Python API на `127.0.0.1`, свободный порт, открытие браузера, защита от второго экземпляра.
- Загрузка утверждённого `soul/personality.json` (Альбедо + Рем + Рафталия).
- Локальная SQLite для событий запуска, логи, чёрно-золотой HTML5 Canvas экран.
- Минимальная панель состояния вместо множества настроек.

**Пока не работает:** общение с облачной моделью, голос, обучение SOUL ACADEMY и полноценная память. Поле чата отключено до настоящего подключения LLM.
