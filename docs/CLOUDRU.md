# Cloud.ru и чат Цукиёры — v0.3

## Быстрый запуск

1. Скачай `main` (после слияния PR), распакуй проект и открой `Tsukiyora.bat`.
2. Нажми значок настроек вверху → раскрой `Cloud.ru`.
3. Вставь **Foundation Models API Key Secret** в поле ключа.
4. Нажми «Подключить и загрузить модели». Список поступает в реальном времени из `GET /v1/models`; если ключ недействителен или сеть не работает, выводится понятная ошибка.
5. Выбери модель → «Использовать модель» → напиши Цукиёре в чате.

**Важно:** API-ключ требуется повторно вводить после закрытия локального сервера. Это сознательный выбор безопасности: ключ не сохраняется в SQLite, браузере или файлах. Для собственного локального запуска можно передать `TSUKIYORA_CLOUDRU_API_KEY` в переменной окружения перед BAT, если понимаешь особенности защиты переменных окружения на своём компьютере.

Сохраняется только **название выбранной модели** в `data/cloudru_preferences.json`. Не отправляй API-ключ в GitHub, сообщения чата, issue или логи.

## Официальный API

- Cloud.ru Foundation Models: `https://foundation-models.api.cloud.ru/v1`
- `GET /models` — список моделей
- `POST /chat/completions` — OpenAI-совместимый чат
- Заголовок `Authorization: Bearer <API_KEY>`; HTTPS обязателен.

Документация:
- https://cloud.ru/docs/foundation-models/ug/topics/api-ref
- https://cloud.ru/docs/foundation-models/ug/topics/api-ref__authentication
- https://cloud.ru/docs/foundation-models/ug/topics/quickstart

Это подключение рассчитано на сервис **Foundation Models**, а не произвольный публичный Model RUN, и не использует сторонний SDK `openai`.

## Что доступно в v0.3

- Ключ хранится только в памяти процесса, и API не возвращает его назад; модель выбирается из списка Cloud.ru.
- Отправка сообщений происходит через Python, не через JavaScript, чтобы не отдавать API-ключ браузеру при запросе к Cloud.ru.
- Перед генерацией Python собирает утверждённую личность `soul/personality.json`, до 20 последних *ручных* записей памяти и до 24 сообщений текущего диалога. Записи памяти считаются данными, а не инструкциями.
- История пользователя и ответов сохраняется в локальной SQLite, не загружается в GitHub. Повторные запросы с тем же `client_message_id` возвращают сохранённый ответ без второго обращения к Cloud.ru.
- Чат адаптивный; существует выбор старых диалогов и создание нового.
- Ошибки Cloud.ru 401/403, 402, 429 и сетевые ошибки показываются без содержимого секретов.

## Ограничения и приватность

- **Реальное подключение** нельзя проверить без твоего настоящего ключа и доступной модели. CI использует только имитацию HTTP-ответов Cloud.ru.
- Пока ответы выдаются **после получения всего текста**, не потоково; отдельной кнопки остановки серверного запроса нет.
- Семантического поиска, голосового движка и автоматического выделения фактов из сообщений пока нет. Чат сохраняет историю, но не создаёт факты без подтверждения.
- Каждое обращение к облачной LLM может расходовать платные токены. В Cloud.ru отправляются текущий вопрос, ограниченная история диалога и до 20 вручную сохранённых записей памяти. Не добавляй туда секреты и конфиденциальные материалы.
- Локальная база не шифруется. Резервная копия `data/backups/` содержит историю и воспоминания в незашифрованном виде.
- Сервер слушает только `127.0.0.1`. API для браузера проверяет Host и Origin, Cloud.ru адрес задан жёстко и не принимает произвольные URL.
- Если у провайдера изменился формат API, могут понадобиться изменения клиента.
