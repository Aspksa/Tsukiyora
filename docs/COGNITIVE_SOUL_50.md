# Cognitive Soul 5.0 — единый безопасный когнитивный центр

Cognitive Soul 5.0 объединяет существующие модули версий 1–4 под одним локальным планировщиком, без замены SQLite, API, исходной памяти или личности. Это не новое обучение весов LLM и не автономное сознание.

## Что изменилось

До V5 фоновый Python-поток запускал одновременно постоянную очередь Maintenance.tick и отдельный цикл CognitiveCore.cycle каждые 15 минут. Они повторяли часть задач: RAG-индексацию, проверки качества памяти, Academy, консолидацию личности и обновление уроков.

Теперь **один поток, одна существующая очередь maintenance_queue в SQLite**. Отдельный циклический повторный обход удалён из фонового работника; Core.cycle сохранён для совместимости как однократная идемпотентная сводка (без полного повторного индексирования). Старые таблицы и API версий 1–4 не удалены. Миграция использует только CREATE TABLE IF NOT EXISTS и INSERT OR IGNORE. Ни один существующий документ не переносится или переписывается.

Старые задания сохраняют прежние интервалы и функции: целостность SQLite, FTS, векторный кеш, слои памяти, резервные копии раз в 5 часов, Academy, персона, аудит источников, документы и история диалогов.

## Новые задания в той же SQLite-очереди

| Имя | Интервал | Суть |
| --- | --- | --- |
| cog5_links | 30 минут | Перестроить локальные связи максимум четырёх недавних подтверждённых воспоминаний |
| cog5_skills | 30 минут | Сгруппировать кандидатов навыков из явной обратной связи |
| cog5_hypotheses | 30 минут | Создать исключительно неактивные кандидаты V3/V4 после повторных отрицательных оценок |
| cog5_simulator | 1 час | Проверить структуру до 12 разрешённых стратегий без запуска LLM |
| cog5_insights | 1 час | Зафиксировать по ID потенциально устаревшую/противоречивую память и ожидающие вопросы |
| cog5_budget | 1 час | Локально подсказать, какие эксперименты нуждаются в проверке, без оплаты |
| cog5_digest | 6 часов | Сохранить не более одной агрегированной сводки в сутки по UTC |

Интервалы ориентировочные: диалог и перегрузка очереди могут задержать фоновые задачи. После закрытия Tsukiyora ничего не выполняется. После аварийного перезапуска очередь восстанавливается из SQLite, ошибки фиксируются без секретов и задачи получают время повторной попытки.

История ограничена 350 записями, сводки — 90 днями. В старой таблице cognitive_cycles сохраняются только 120 последних агрегированных записей.

## Безопасность автоматического режима

**Разрешено автоматически:** локальные индексы, проверка источников, недеструктивные сигналы ошибок, неактивные гипотезы, отчёты, резюме опыта и локальные проверки правил.

**Не разрешено автоматически:** платные запросы Cloud.ru, запуск V3/V4 облачных бенчмарков, утверждение навыков и стратегий, добавление непроверенных фактов в память, изменение защищённой личности, удаление данных, саморедактирование кода, произвольные интернет-исследования или действия.

Режим фиксирован: safe_local. Можно только поставить его на паузу или возобновить. Исходные V3/V4 инструменты с платными испытаниями остаются в разделе расширенных функций и требуют отдельного ручного подтверждения.

Локальный симулятор оценивает лишь допустимость комбинации правил, а не «интеллект модели». Отзывы и предупреждения не доказывают истинность утверждений. Отметка «проверено» меняет только метаданные предупреждения, не исходную память.

## HTTP API

Чтение:

    GET /api/soul/unified
    GET /api/soul/unified/reviews

Только same-origin JSON-запросы и явное подтверждение:

    POST /api/soul/unified/control
    {"enabled":false,"confirmed":true}

    POST /api/soul/unified/control
    {"enabled":true,"confirmed":true}

    POST /api/soul/unified/tick
    {"confirmed":true}

    POST /api/soul/unified/review
    {"id":1,"confirmed":true}

Один вызов tick выполняет максимум одну доступную локальную задачу и откладывается, если активен чат или другой tick. Пауза не отключает чат и не мешает запускать ручные инструменты.

## Интерфейс

Tsukiyora.bat → Настройки → Опыт и биография → Cognitive Soul 5.0.
Там показываются очередь, история, локальные предупреждения и сводка, доступна пауза и ручной запуск одного шага.

Все старые функции Cognitive Soul 1–4 сохранены под раскрываемым пунктом «Расширенные инструменты». Чёрно-золотая тема и существующий стек не меняются.

## Проверки

    python -m unittest discover -s tests -v
    python launcher.py --self-test

GitHub Actions проверяет Linux/Windows, Windows BAT и SQLite с миллионом записей. В CI реальная модель Cloud.ru не вызывается. На ПК с пользовательским Cloud.ru нужна отдельная ручная проверка чата, но фоновые задачи никогда не используют эту модель.
