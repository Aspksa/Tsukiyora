# Cognitive Soul 7.0 — единый контур развития

Не новый агент или LLM, а объединение уже существующих модулей V1–V6:
одна SQLite, одна очередь maintenance_queue, Python API, существующий чат.
Нет новых сервисов, Docker, Ollama, зависимостей или изменений личности.

## 20 пунктов: что реализовано и что переиспользовано

1. Единый реестр: read-only registry() собирает существующие таблицы ExperienceSkills, V4 Evolution, V6 SkillForge и SOUL ACADEMY с источником вида source:id без копирования данных.
2. Общее обучение: повторно используются CognitiveCore.feedback, AcademyMetrics, SkillForge.feedback; V7 оценивает готовность.
3. Память источников: сохраняются memory_links, forge_evidence, parent_id, ConversationMemory и PersonaArc.
4. Общая оценка: отдельные парные результаты сравнения со старым методом, без смешивания с эвристическими структурными баллами V6.
5. Единый Cloud.ru: переиспользуются CloudSession, ResourceGuard, лимиты V6; V7 не инициирует ни один платный запрос.
6. Поиск пробелов: V6 discover + V5 insights + V7 plan() для слабых и непроверенных навыков.
7. Конструктор: V6 BASE, STEPS, variant, compose без исполнения сгенерированного кода.
8. Исправление ошибок: V6 feedback создаёт новые версии черновиков, не переписывая предыдущие.
9. Проверка результата: V7 add_case фиксирует сопоставление двух ответов с эталоном, минимум 8 разных вопросов.
10. Конкуренция: V7 verdict требует минимум 2 дополнительных верных ответа, ноль регрессий, одна модель на все примеры.
11. Составные навыки: переиспользуются V6 compose и transfer; на новые кандидаты распространяется новый порог качества.
12. План самообучения: старые curriculum + V7 plan, который показывает недостающие контрольные проверки.
13. Один планировщик: добавлены cog7_review (30 минут), cog7_health (час), cog7_daily (6 часов) в существующую SQLite-очередь.
14. Память и противоречия: переиспользуются проверки V5, число открытых конфликтов без удаления или исправления фактов.
15. Откат: сохранён старый автоматический контроль по оценкам, новый ручной маршрут rollback; история не удаляется.
16. Самодиагностика: локальный SQLite quick_check, foreign_key_check, состояние очереди и счётчики предупреждений; без Cloud.ru ping.
17. Контроль нагрузки: тот же ограниченный Python worker и приоритет чата; тяжелая SQLite-проверка вынесена из частых status-запросов.
18. Без дублей: fingerprint V6, уникальные хеши контрольных вопросов, идемпотентные суточные сводки, восстановление очереди.
19. Непрерывная личность: сохранены personality.json, PersonaContinuity, PersonaArc и исходные воспоминания; V7 не изменяет характер.
20. Диалог: карточка нового навыка отправляет на проверку, если нет доказательств, и позволяет вручную одобрить или откатить.

## Доказательный порог

Для каждого нового навыка, созданного после установки V7:
- четыре пройденных локальных структурных теста Skill Forge;
- минимум 8 различных подтверждённых пользователем парных контрольных примеров;
- одинаковая модель и сопоставимые условия, заявленные пользователем;
- новый метод даёт минимум на 2 точных совпадения с эталоном больше старого;
- ни одной регрессии;
- ручное подтверждение включения.

Проверка встроена в исходный серверный метод SkillForge.decide: старые и новые интерфейсы НЕ могут включить новый навык в обход требования. Граница новых ID фиксируется однократно в SQLite; существующие навыки не отключаются при обновлении.

**Ограничение:** V7 оценивает ответы, предоставленные пользователем. Приложение не может подтвердить, что ответы действительно получены из заявленной LLM; это не полноценный независимый A/B-тест и не доказательство роста интеллекта. Нормализованное строковое совпадение не заменяет смысловую экспертизу. История ответов не передаётся в Cloud.ru; сохраняются только хеш вопроса, метка модели и бинарные исходы. Для настоящих LLM-испытаний нужны отдельно разрешённые расходы.

## API

GET:
- /api/soul/cognitive7
- /api/soul/cognitive7/registry
- /api/soul/cognitive7/plan
- /api/soul/cognitive7/health
- /api/soul/cognitive7/verdict?skill_id=1

POST, только same-origin JSON с ручным подтверждением:
- /api/soul/cognitive7/case: skill_id, question, expected, baseline_answer, candidate_answer, model, confirmed:true, attested:true
- /api/soul/cognitive7/approve: skill_id, confirmed:true
- /api/soul/cognitive7/rollback: skill_id, confirmed:true

В настройках Cognitive Soul 7.0 есть реестр, диагностика и форма сравнения. Карточки новых навыков в чате не включают навык до доказательств.

## Сохранность и тесты

Не перемещались данные, история диалогов, soul/personality.json, документы, настройки Cloud.ru и резервные копии. Не создавались новые платные лимиты и задачи в Cloud.ru. Ранее отдельно разрешённый режим V6 (при явном включении: максимум 1 автоматическая попытка в сутки) не увеличен.

Проверки:
- python -m unittest discover -s tests -v
- python launcher.py --self-test
- python scripts/test_million_atlas.py
