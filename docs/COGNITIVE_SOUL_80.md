# Cognitive Soul 8.0 — Living Personality & Autonomous Growth

Единое **локальное** развитие личности и самостоятельности поверх уже
работающих V1–V7. Нет заявлений о сознании, субъективных чувствах,
«внутреннем мышлении», самостоятельной перепрошивке весов LLM или
доказанном повышении интеллекта.

## Все 20 пунктов: переиспользование и реализация

1. Постоянное ядро: исходный soul/personality.json неизменен, проверяемая PersonaContinuity остаётся источником привычек и прошлого.
2. Эволюция характера: три разных явно позитивных отзыва с пояснениями могут предложить одну из четырёх безопасных корректировок **стиля**; применение требует подтверждения и не меняет оригинальный характер.
3. Автобиографическая память: повторно используется PersonaContinuity.timeline(), PersonaArc и SoulGrowth; V8 хранит лишь агрегаты и ссылки на цели.
4. Внутреннее состояние: programmatic state с условной уверенностью, нагрузкой очереди и количеством исследовательских вопросов; без притворства, будто это чувства.
5. Индивидуальная манера общения: фиксированные строки разрешённых стилей после явного подтверждения входят в CognitiveCore.guidance(); при отзыве исходных положительных оценок стиль перестаёт применяться.
6. Собственные учебные цели: V8 обнаруживает задачи из реально подтверждённых предупреждений Academy, неоценённых навыков V7, сомнений памяти и исследовательских вопросов.
7. Автономная учебная программа: три ограниченных локальных контрольных шага на цель, с checkpointing и восстановлением после сбоя.
8. Любопытство: читает только существующие cognitive_next_questions и предлагает локально проверить недостающие знания; не выдумывает источники и не запускает веб-поиск.
9. Рабочий дневник: source_id, тип события и числовые счётчики в SQLite; не хранит сырой текст ответов.
10. Самокритика: повторно использует AcademyMetrics и V7 evidence gate, фиксирует отмеченные пользователем слабости.
11. Уроки из неудач: прежние Skill Forge revisions, AcademyRollback и V7 comparisons; никаких автоматических правок кода или промпта персонажа.
12. Перенос навыка: прежний V6 transfer и контроль V7; V8 не включает его без отдельного доказательного теста и подтверждения.
13. Самостоятельная постановка задач: idempotent, fingerprint-based safe goals из известных источников.
14. Исследование: разрешённый локальный поиск по фрагментам уже импортированных документов **только по явно одобренным исследовательским вопросам** и только при включённом разрешении indexed_documents. Сохраняются ID источников, редакции, хеши цитат, но не текст.
15. Планирование и продолжение: 3 checkpoint-а с UNIQUE(goal_id,stage), переживают рестарт; результат требует просмотра пользователем.
16. Фоновые действия: шесть локальных заданий cog8_discover, cog8_practice, cog8_reflect, cog8_daily, cog8_health, cog8_research **в той же единой SQLite-очереди**, приоритет активного чата сохраняется.
17. Инициатива: настоящие pending-предложения из SQLite отображаются отдельной карточкой в чате, можно одобрить/отклонить, без подмены речи LLM.
18. Уровни автономности: 0 выключено, 1 наблюдение, 2 локальная работа, 3 локальная работа плюс предложения в чате. Три явно переключаемых локальных права. Внешние действия/платные запросы/память/активация навыков/перезапись личности **не предоставляются** V8 вообще.
19. Самодиагностика: проверка предупреждений единой очереди, статус существующих V7 health и общая логика отката V6; новых независимых демонов нет.
20. Дневник эволюции: один агрегат за день, хранится локально, содержит сколько целей/проверок/отзывов имеется, но не утверждает, что навыки объективно улучшились.

## Уровень 3 и границы прав

Согласно выбору пользователя, на новой БД включён уровень 3.
Режим 3 означает **расширенную безопасную локальную автономность**, а не
самостоятельные расходы Cloud.ru или разрешение на изменения в GitHub.
Локально по умолчанию разрешены:
- анализ утверждённых сигналов и безопасная автономная постановка целей;
- ограниченные локальные проверки и журнал;
- предложения в чате, не являющиеся сообщениями нейросети.

Работа с метаданными существующих индексированных документов требует
дополнительного явного включения. Файлы и содержимое документов не читаются
этим модулем. Отдельная система импортирования и RAG остаётся прежней.

Запрещены для V8 при любом уровне (даже 3): paid_cloud, external_actions,
rewrite_persona, activate_skills и modify_user_memory. Эти значения
невозможно включить через API или UI V8. **Существующая настройка Cloud.ru
Skill Forge 6.0 не изменяется**; V8 не запускает ни одного нового запроса.
Автоматические платные тесты не проводятся.

После перехода на уровень 0 новые фоновые операции **8.0** прекращаются,
а уже созданные записи остаются сохранены. Это не выключает весь
существующий V1–V7 планировщик; для него уже есть отдельные настройки.

## Из чего рождается «развитие личности»

- Только одобренные источники: PersonaContinuity, PersonaArc, SoulGrowth,
  существующие SQLite-связи и оценка Academy.
- Кандидаты манеры общения используют фиксированный безопасный набор
  (clarity, sources, brevity, gentle), минимум три разных явных позитивных
  отзыва с соответствующими текстовыми пояснениями.
- Необработанные заметки и сообщения не становятся промпт-инструкциями.
- В чате Цукиёра **предлагает** стиль. Применить или отклонить может
  только пользователь; отзыв подтверждения прекращает влияние на ответ.
- Ядро personality.json остаётся вне любых механизмов автоматической
  записи. Восьмая версия не обещает эмоционального опыта или сознания.

## Схема и REST API

Новые таблицы: soul8_settings, soul8_permissions, soul8_goals,
soul8_checkpoints, soul8_proposals, soul8_styles, soul8_journal.
Оригинальные сообщения, персональные воспоминания и история SkillForge
остаются в своих таблицах — копий в V8 нет.

Read-only GET localhost, same-origin:
- /api/soul/living8
- /api/soul/living8/agenda
- /api/soul/living8/proposals
- /api/soul/living8/journal
- /api/soul/living8/diary

POST (обязательное confirmed:true и same-origin):
- /api/soul/living8/control: {"level":3,"confirmed":true}
- /api/soul/living8/permission:
  {"scope":"proactive_chat","enabled":false,"confirmed":true}
- /api/soul/living8/decision:
  {"proposal_id":1,"approve":true,"confirmed":true}

Никаких endpoints для внешней автономности и платных вызовов не создаётся.

## Стек, совместимость, тесты

TypeScript + HTML5 Canvas + CSS, Python — единственный API, Node только
сборка/выдача фронтенда, SQLite — единственная база. Существующие папки,
BAT и UI сохраняются. Без Docker/Ollama, новых dependencies и служб.

CI в Windows/Linux: python -m unittest discover -s tests -v,
проверка Windows BAT, синтаксис браузерного JS, сохранность JSON личности,
стресс-тест SQLite на миллионе записей. Добавлены тесты режимов 0–3,
запрещённых прав, происхождения целей, восстановления checkpoint-ов,
истории, отзывов, предотвращения скрытых Cloud.ru-вызовов и API Origin.
