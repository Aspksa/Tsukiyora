# Tsukiyora 12.0 — Living Mind & Inner World

Реализованы выбранные пользователем **19 пунктов**: `1, 2, 3, 5–20`. **Пункт 4 намеренно исключён** (модель интереса/нагрузки/псевдоэмоционального состояния не добавлялась).

## Что такое «внутренние мысли»

Это **проверяемые локальные рабочие заметки** с типом источника, его настоящим ID, фиксированным вопросом и правом пользователя проверить/закрыть заметку. Это **не** скрытая цепочка рассуждений языковой модели, не непрерывный поток генерации, не доказательство наличия сознания/чувств и не обучение весов нейросети.

Модуль `tsukiyora/cognition/inner_world12.py` не имеет кода сетевых запросов или собственного потока. Источник истины остаётся в уже существующих таблицах; только состояние заметок хранится в компактной `soul12_notes`. Она содержит **только** `kind, source_table, source_id, status` и даты; в неё не копируются переписки, тексты документов, пароли, личная биография или модельные рассуждения.

## Автоматический цикл

`cog12_reflect` добавлена **в прежнюю** `Maintenance.JOBS` с периодом 1800 секунд. Запускается тем же `CognitiveWorker`, который уступает активному чату.

1. Проверяет V8 уровень автономности **≥ 2** и `local_practice=true`.
2. По существующим индексам и таблицам отбирает до двух актуальных записей каждой категории (не более восьми новых заметок за один запуск).
3. Сохраняет только `kind + реальный source_id` через `INSERT OR IGNORE`. Не создаёт повторные заметки после перезапуска или повторного цикла.
4. Хранит до 280 последних заметок. Удаление *метаданных блокнота* не затрагивает источники.
5. Записывает один агрегированный дневник на день в V8. Новые тексты пользователя/содержимое документов туда не записываются.
6. Пункты V5/V7/V8/Academy/Forge сохраняют собственных владельцев, расписание и права. Изменения личности, подтверждённой памяти, активация навыков и платные Cloud.ru вызовы запрещены.

### Проверка актуальности

Перед отображением каждой заметки `notes()` перепроверяет исходную строку: если пользователь отклонил вопрос, исправил источник, завершил цель или удалил воспоминание, заметка перестаёт отображаться как актуальная. `inspect` покажет текущую валидность источника, а не выдуманное объяснение.

### Инициатива

`chat_hint` может использовать **одну** актуальную заметку из блокнота, только если сообщение пользователя относится к соответствующей теме и V8 разрешает инициативу на уровне 3. Текст формируется фиксированным шаблоном без приватных данных; в ответе нельзя выдавать предложение за уже выполненную проверку. Никаких самостоятельных сообщений пользователю, внешних действий или Cloud.ru запросов по расписанию.

## API и интерфейс

- `GET /api/soul/inner12`: статус, выбранные пункты, последнее дневниковое событие и единая очередь.
- `GET /api/soul/inner12/notes?limit=20`: актуальные заметки с настоящими ID источников.
- `POST /api/soul/inner12/inspect` с `{"note_id": 1}`: только локальная проверка источника.
- `POST /api/soul/inner12/dismiss` с `{"note_id": 1,"confirmed": true}`: закрывает *только заметку*; исходные данные остаются прежними. Same-origin везде для запросов записи.
- В настройках — **Tsukiyora 12.0**, источник, фиксированный вопрос, кнопка проверки и закрытия.
