# Память Цукиёры · v0.2

## Что реализовано

Локальная база `data/tsukiyora.sqlite3` и Python-модуль `memory_store.py` хранят данные **в папке проекта**, не в GitHub и не в облаке.

- **Воспоминания** четырёх видов: факт, предпочтение, событие, биография.
- **Проверяемое происхождение:** у записи есть `source_type`, `source_ref`, `verification_state`, дата создания и дата изменения. Ручные сведения имеют статус `user_reported` (сообщено человеком, не независимо проверено).
- **Точный локальный поиск** по тексту (включая кириллицу) и категории. `LIKE`, без ложного заявления о семантическом / векторном поиске.
- **Защита от повторов:** одинаковое содержимое того же типа не сохраняется дважды. Исправления и удаление фиксируются в `memory_revisions`; удалённая запись исключается из активного поиска.
- **Диалоги:** отдельные таблицы разговоров и сообщений, клиентские идентификаторы защищают от повторной записи после повторной отправки. Транзакции SQLite сохраняют пачку сообщений целиком или откатывают её при ошибке.
- **Резервные копии:** по кнопке «Создать резервную копию» делается согласованная SQLite-копия через `Connection.backup()` с проверкой `integrity_check`. Локально, в `data/backups/`. Данные не отправляются наружу.
- **Интерфейс:** одна сворачиваемая секция «Воспоминания» внутри прежних настроек; добавление, поиск, исправление, удаление и резервная копия. Пустой интерфейс не показывает демоданные.

## Чего пока нет

- Цукиёра пока **не отвечает**: Cloud.ru и другие нейросети не подключены, существующее поле чата отключено.
- Автоматическое запоминание разговоров **не включено**, пока нет рабочего чата. Подготовленный API для сохранения сообщений будет использовать следующий этап разработки.
- **Нет** автоизвлечения фактов, векторного поиска, фонового обучения, проверок противоречий по смыслу и внешней проверки достоверности.
- **Нет** восстановления резервных копий из интерфейса — эту операцию следует делать отдельно после подтверждения и проверки совместимости. Резервная копия без контроля доступа не является шифрованием.
- История диалогов не загружается в интерфейс чата до реализации Cloud.ru; она доступна через локальный API.

## Локальный API

Все маршруты слушают только `http://127.0.0.1:<порт>`. Для изменения данных используется `application/json`; защищены Host и Origin, нет CORS для внешних сайтов. Нельзя выставлять этот сервер в интернет без дополнительной защиты.

| Метод и маршрут | Назначение |
|---|---|
| `GET /api/memory/status` | Сколько воспоминаний, разговоров, сообщений |
| `GET /api/memory?query=...&kind=...&limit=50` | Текстовый поиск |
| `POST /api/memory` | `{"kind":"preference","content":"Люблю зелёный чай"}` |
| `PUT /api/memory/1` | `{"content":"Уточнённый текст","reason":"Исправлено"}` |
| `DELETE /api/memory/1` | Исключить запись из активной памяти, оставить версию |
| `POST /api/memory/conversations` | `{"title":"Новый разговор"}` |
| `GET /api/memory/conversations` | Список разговоров |
| `POST /api/memory/messages` | `{"conversation_id":"...","messages":[{"role":"user","content":"Привет","client_message_id":"uuid"}]}` |
| `GET /api/memory/messages?conversation_id=...&before_id=...&limit=100` | Постраничная история сообщений |
| `POST /api/memory/backup` | Создать локальную проверенную копию |

Записи на диске не отбрасываются при пагинации. Максимальный размер одного сообщения — 32 000 символов, заметки — 8 000, запроса API — 65 536 байт.

## Проверка

```powershell
python -m unittest discover -s tests -v
```

GitHub Actions проверяет сборку Python и тесты на Windows и Linux; запуск BAT на Windows проверяется smoke-тестом. На личном компьютере двойной щелчок BAT и отображение окна нужно проверить дополнительно.

## Приватность

`data/` и `runtime/` в `.gitignore`. Никогда не коммитить настоящие личные сведения, API-ключи и резервные копии в публичный GitHub. Данные не зашифрованы: используйте защиту доступа к компьютеру/SSD и храните резервные копии в безопасном месте.
