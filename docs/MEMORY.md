# Память Цукиёры · v0.4

Все данные сохраняются локально в `data/tsukiyora.sqlite3` (SQLite, WAL). `data/` исключена из Git. Память не шифруется, поэтому защищайте доступ к SSD и создавайте резервные копии.

## История и факты

- `conversations`, `messages`: история разговоров, не ограниченная последними 100 сообщениями на диске. Пагинация по `before_id`; повтор с прежним `client_message_id` не дублирует сообщение.
- `memory_items`: факт, предпочтение, событие, биография, источник (`source_type/source_ref`), статус доверия `user_reported`, дата. Это значит «пользователь сообщил», а не «мир независимо подтвердил».
- `memory_revisions`: исправления и мягкое удаление с историей.
- `memory_suggestions`: автоматические **предложения**, выделенные из явно выраженных фраз пользователя; только подтверждение человека переносит запись в `memory_items`.
- `memory_links`: найденные связи `related` и сигналы `possible_conflict`. Возможный конфликт не считается проверенным противоречием; требуется просмотр источников.
- `soul_journal`: завершённые разговоры, принятые воспоминания, подтверждённые изменения манеры общения. Защищённые ценности персонажа не меняются.

## Поиск

Обычный локальный поиск `GET /api/memory` работает без облака. Гибридный поиск в `SoulGrowth.retrieve()` сравнивает слова и нечёткую строковую похожесть. Кнопка «Поиск по смыслу» делает дополнительное ранжирование через LLM Cloud.ru (`POST /api/soul/search`, `semantic: true`) и может расходовать токены. Поскольку модель ранжирует только локально найденных кандидатов, синонимы без общих слов могут быть пропущены. На этом этапе это **не полноценная векторная RAG-система**.

## Ручное управление

В Настройках → Воспоминания доступны поиск, добавление, исправление, удаление, резервная копия, предложения для подтверждения и история развития. Вся информация об источниках остаётся в SQLite. Принятые воспоминания и стиль используются в последующих ответах Цукиёры.

## Резервные копии

Используется штатный SQLite `Connection.backup()` с `PRAGMA integrity_check`; `data/backups/`. Копируется вся история, включая новые таблицы. Восстановление через UI ещё не реализовано — нельзя без проверки перезаписывать работающую базу. Не загружайте резервные копии в публичный GitHub.

## Безопасность и ограничения

- Сервер слушает только `127.0.0.1`. Браузерные запросы проверяют Host, Origin и JSON.
- Нет автономного сохранения неподтверждённых фактов, обучения на закрытых документах и саморедактирования кода.
- Отправка в Cloud.ru включает выбранные релевантные записи памяти и контекст беседы. Передавайте только данные, которыми можно делиться с провайдером.
- Нет внешнего векторного хранилища или сторонних зависимостей.

Подробности: [Пять этапов Цукиёры](LIVING_MEMORY.md).

## Проверка

```powershell
python -m unittest discover -s tests -v
```

GitHub Actions проверяет Windows/Linux на отдельном тестовом экземпляре SQLite и имитирует ответы Cloud.ru. Реальная сеть и API-ключ проверяются пользователем после установки.
