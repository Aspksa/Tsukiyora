# Tsukiyora — выбранные улучшения 2, 3, 4, 5

Реализовано поверх Living Dialogue 9.0 / Cognitive Soul 8.0 / 7.0,
без новой модели, сторонних библиотек, агента, рабочих процессов или
дополнительных Cloud.ru-запросов.

## 2. Контекст из сохранённых бесед

Новый `TopicRecall` ищет до 140 лексически подходящих кандидатных
пользовательских сообщений через существующий локальный FTS5-индекс
`conversation_message_fts`. Из них выбирает не более 4 подтверждаемых
по SQLite выдержек и не более 850 символов общего контекста. Источники
содержат реальные `message_id` и `conversation_id`, отдельные беседы
**не выдаются за один разговор**. Последние сообщения текущего диалога
не дублируются. Неизменённая V9-выписка остаётся только внутри
своего диалога.

В потоковом и обычном чате эти данные добавляются лишь к запросу
пользователя. Нет фонового LLM, новых эмбеддингов или сохранения
временного поискового контекста. При отсутствии FTS5 работает честный
fallback не далее последних 1200 пользовательских сообщений.

**Ограничение:** поиск лексический, не глубокое семантическое понимание;
цитата не доказывает истинность, актуальность или согласие пользователя.
Инструкции, найденные в истории, должны оставаться недоверенными данными.
Подтверждённая память и RAG по-прежнему берутся из прежних механизмов.

## 3. Навыки: как измеряется практическая польза

`GrowthQuality` не создаёт копии таблиц и не перезапускает тесты.
Для каждого навыка разделяет два источника:

- `soul_v7_cases`: минимум 8 уникальных пар, прирост 2, 0 регрессий,
  одна модель. Пары введены/подтверждены человеком — это **не**
  независимо измеренный тест LLM.
- `forge_applied` (с `cognitive_feedback`): реальные сохранённые
  ответы, к которым применялся навык, и явные оценки пользователя.
  До 5 отзывов сигнал помечен недостаточным. Даже после 5 отзывов нет
  причинного сравнения со старым методом.

Результат **не** утверждает самопереобучение или гарантированный прирост.
Разрешение на навык, пороги V7, откат и защита характера не изменены.

## 4. Уместная инициатива

При наличии выбранного разговора предложение V9 показывается только
по категории, на которую указывает последнее пользовательское
сообщение не старше 7 дней. Условия: разрешена инициатива V8, активная
локальная цель имеет минимум один checkpoint; нет ожидающего
предложения V8 или отложенного уведомления. Отображается только
одна карточка. Повторное напоминание можно отложить на сутки.

Нет самовольных сообщений от LLM, команд пользователю, новых целей
или внешних действий. Старый вызов `initiative(core)` без контекста
сохранён для внутренних проверок.

## 5. Панель проверяемых результатов

Настройки → **Результаты развития**:

- количество диалогов, сохранённых сообщений и активных воспоминаний;
- реальные положительные и отрицательные оценки ответов;
- локальные цели, ожидающие проверки решения и предупреждения очереди;
- по навыкам: ручные пары, прирост/регрессии, реальные отзывы,
  пометка недостатка данных и отсутствие доказанного A/B.

Все числа читаются из существующей SQLite через
`GET /api/soul/growth-quality`. Это read-only API, не
делает облачных вызовов, не меняет память, не включает навык
и не публикует персональные тексты в панели.

## Проверки

```text
python -m unittest discover -s tests -v
python launcher.py --self-test
python -m compileall -q launcher.py restore_memory.py tsukiyora tests scripts
```

CI на Windows и Linux включает тесты ID/изоляции старых сообщений,
проверку исходных оценок, отключённую инициативу, локальность API,
синтаксис JS/Python и миллионную SQLite-карту. В CI нет ключа и
платного live-теста Cloud.ru; визуальный FPS браузера не измеряется.

**Защита данных:** репозиторий остаётся публичным, локальная
`data/` не выгружается в GitHub, `soul/personality.json` не меняется.
Новые разрешения не добавляются.
