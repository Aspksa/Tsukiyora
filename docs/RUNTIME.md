# Цукиёра — локальный запуск v0.1

## Что уже реализовано
- Одна переносимая папка: BAT + локальный Python HTTP API + HTML5 Canvas + CSS + JavaScript-совместимый TypeScript.
- Запуск на двойной щелчок (Windows); сервер слушает только 127.0.0.1 и выбирает свободный порт.
- Защита от второго экземпляра, открытие браузера, логирование с ротацией.
- Чтение и проверка утверждённого профиля души из \`soul/personality.json\`.
- Создание локальной базы SQLite для событий запуска.
- Чёрно-золотой одностраничный экран с визуализацией ядра личности.
- API состояния: \`/api/health\`, \`/api/status\`, \`/api/personality\`.
- Игнорирование приватных данных через \`.gitignore\`.

## Ещё НЕ реализовано
- Облачная LLM (Cloud.ru или другие): нет настройки ключа и отправки сообщений.
- Отправка сообщений в чате, потоковые ответы и остановка генерации.
- Голосовой движок.
- Биографическая и семантическая память, SOUL ACADEMY и непрерывное развитие.
- Резервное копирование SQLite и восстановление. SQLite пока содержит только события запуска.

Интерфейс не делает вид, что это уже работает. Поле чата отключено до реального подключения модели.

## Как запустить
1. В GitHub выбрать ветку \`feat/soul-core-runtime\` и скачать ZIP репозитория.
2. Распаковать ZIP в любую папку на ПК или внешний SSD.
3. Нужен Python 3.10+ (доступен как \`py -3\` или \`python\`) либо заранее подготовленный переносимый \`runtime/python/python.exe\`.
4. Открыть \`Tsukiyora.bat\` двойным щелчком.
5. Браузер откроет \`http://127.0.0.1:<свободный порт>\`. Адрес также появится в консоли.
6. Закрытие консоли остановит сервер. Память и логи сохранятся в \`data/\`.

Node.js и npm **не нужны для первого экрана**: \`ui/app.ts\` написан в JS-совместимом подмножестве TypeScript и отдаётся браузеру как JavaScript. При переходе к полноценному TS с типами добавим сборку на уже согласованном Node.js, только для frontend.

## Безопасность
- На localhost, без публичного доступа к серверу.
- Не хранить ключи, личные файлы и базу памяти в GitHub — репозиторий публичный.
- \`data/\` и \`runtime/\` исключены из Git, ключи не предусмотрены в этом этапе.
- Без Docker, Ollama, локальной LLM и сторонних Python-библиотек.
