# Tsukiyora 11.0 — Ultimate Cognitive Memory

## Three requested stages; reuse instead of duplication

V11 coordinates **existing** memory, dialogue, graph, V5/V7/V8/V10,
Academy and Skill Forge engines. It does not add a second local database,
worker, agent, Python API, web dependency, local LLM or Cloud.ru background
call. The runtime is still TypeScript + HTML5 Canvas + CSS, Python-only API,
Node for frontend, and SQLite, launched by one portable BAT on Windows.

**This is an inspectable engineering implementation, not a claim that a
cloud model understands everything, never forgets, or has been retrained.**
Lexical heuristics, fixed multilingual aliases, a limited graph traversal and
source citations do not establish real-world truth.

## Stage 1 — understanding and safe long-term memory (1–20)

| # | Requested capability | Owner / implemented behavior | Limit |
|---|---|---|---|
| 1 | User intent | Life Cycle 10 + V11 analyze | Lexical heuristics, no mind reading |
| 2 | References ("same", "continue") | V11 detects unresolved referents | Doesn't invent missing context |
| 3 | Multi-topic | V11 bounded subquestion decomposition + V9 history | Up to 3 subquestions, not autonomous planning |
| 4 | Decisions vs ideas | V11 classify, existing memory_suggestions approval | No auto-promotion |
| 5 | Projects | Existing RAG, V5 graph, memory layers | Only sourced data |
| 6 | People/relations | PersonaArc/PersonaContinuity | No inference of personal relationships |
| 7 | Complex questions | Bounded decomposition / existing RAG | Not guaranteed multi-hop correctness |
| 8 | Corrections | MemoryStore revisions and V11 correction detection | User has to approve/perform correction |
| 9 | Languages | Fixed Russian/English/Chinese query aliases | Not general multilingual semantic search |
| 10 | Uncertainty | Source/ref labels and conflict warnings | User reports aren't external proof |
| 11 | Episodes | ConversationMemory indexed original chats | Original text remains source |
| 12 | Semantic facts | MemoryStore + PrecisionMemory | User-approved local facts |
| 13 | Procedures | Existing Skill Forge/V7 gates | No autonomous activation |
| 14 | Working context | User-chat recent history + V10 shared compositor | Token budget limits |
| 15 | Biography | Existing PersonaContinuity | Protected identity |
| 16 | Time | Explicit V11 `as_of` created-at filter | **Not** historical reconstruction |
| 17 | Versions | MemoryStore.memory_revisions | Revisions retained |
| 18 | False memories | MemoryQuality, source labels, V5 review queue | Human review required |
| 19 | Consolidation | Existing growth/quality jobs in same SQLite queue | Never merge user facts silently |
| 20 | Importance | Existing layered memory priority tie-breaker | Relevance wins |

Stage 1 adds `UltimateMemory11.analyze`, `search` and a bounded
`prompt` in the existing V10 shared streaming/synchronous chat path.
Every quoted memory keeps its real ID and is labeled as potentially
unverified. Ambiguous references without context return an empty result
rather than pretending to remember.

## Stage 2 — fast local retrieval (21–30)

| # | Capability | Implementation / reuse |
|---|---|---|
| 21 | Adaptive routing | Empty/ambiguous topic => no database-wide fuzzy scan |
| 22 | FTS5/BM25 | Existing PrecisionMemory, fix empty result fallback |
| 23 | Hybrid search | FTS5 + local graph + previously cached embeddings |
| 24 | Rank fusion | RRF (k=60) across text and cosine-ranked result lists |
| 25 | Graph lookup | Existing sourced `memory_links` one-hop expansion |
| 26 | Reranking | Lexical provenance-aware ranking + bounded cached vectors |
| 27 | Compact context | V10 shared composer + V11 memory packet; IDs intact |
| 28 | Caching | 192 bounded pure lexical-plan entries; never stale result caching |
| 29 | Incremental indexing | Existing `precision_index`, `vector_repair`, FTS triggers |
| 30 | Large scale | Existing Atlas million-row CI; V11 uses bounded candidate sets |

Details:
- No query embeddings are generated by V11. If a saved exact-query vector
  exists, V11 reads it and scans at most 144 recent same-model indexed
  memories; stale per-memory embeddings are excluded by SHA-256.
- Source retrieval is capped: at most 40 FTS candidates, 40 vector
  candidates and one-hop existing graph expansion (limits inherited from
  PrecisionMemory).
- Lexical no-match against working FTS5 returns zero, instead of
  defaulting to fuzzy ranking of 2,500 recent memories. When FTS5 is
  unavailable, local recent fallback is capped at 600 candidates.
- A new reverse index on `memory_links(target_id, source_id)` improves
  source lookup without migrating or rewriting user memories.
- Caching **only pure parsing** is intentional: caching whole search
  results without safe invalidation would surface deleted or corrected
  facts. No new dependencies are needed.
- The `as_of` date filters **creation date** only. It does not pretend
  to reconstruct the historical state of a subsequently corrected fact.

## Stage 3 — feedback, learning, reliability (31–40)

| # | Capability | Owner / behavior |
|---|---|---|
| 31 | Feedback | Existing cognitive_feedback + Life Cycle 10 |
| 32 | Strategy tests | Cognitive Supervisor 7, separate V11 smoke metric |
| 33 | Automatic Academy plan | Existing bounded SOUL ACADEMY jobs |
| 34 | Skills reuse | Existing Skill Forge + approval gate |
| 35 | Regression | Existing academy rollback/V7 verdict |
| 36 | Memory evaluation | New source-ID, revision, temporal, injection, caching tests |
| 37 | Maintenance | Existing queue + new metadata-only `mem11_audit` |
| 38 | Crash recovery | Existing SQLite maintenance state machine |
| 39 | Resource budget | Bounded search/graph/vector pools; chat priority |
| 40 | Diagnostics | `GET /api/soul/memory11` + opt-in self-retrieval benchmark |

V11 registers a single **metadata-only** `mem11_audit` with the
pre-existing `Maintenance.JOBS` queue. It reads counts of active
memories, saved revisions, pending reviews, links, cached vectors,
negative feedback, skill candidates and queue failures. It writes
**at most one UTC daily** numeric summary into V8's existing bounded
`soul8_journal`. The existing owners still run indexing, feedback,
Academy work and V7 gating: V11 does not repeat them.

If V8 autonomy is level 0, V11 audit does nothing. It never runs a
provider, rewrites `soul/personality.json`, updates facts or activates
skills. User approval still guards those actions.

## Inspection

- **GET /api/soul/memory11** — read-only state and data lineage.
- **POST /api/soul/memory11/search** — `{"query":"...","limit":8,
  "conversation_id":"optional","as_of":"YYYY-MM-DD"}`. Same-origin,
  bounded. Returned `history` always carries message AND dialogue IDs.
  Sources are user-reported, not automatically verified. For calls
  with no selected conversation, only approved memory is returned.
- **POST /api/soul/memory11/benchmark** — explicit
  `{"confirmed":true,"count":5}`, local-only and deferred during chat.
  Reports p50/p95 latency and **self-retrieval** recall@k over queries
  derived from existing saved facts. This is *not* an independent
  held-out QA benchmark or proof of a more intelligent model.
- The new **Tsukiyora 11.0** section in settings shows metrics,
  source-linked local search, explicit creation-date filtering and
  opt-in latency test.

## Validation

```sh
python -m compileall -q launcher.py restore_memory.py tsukiyora tests scripts
python -m unittest discover -s tests -v
python launcher.py --self-test
```

GitHub Actions runs Python 3.13 on Windows and Ubuntu, node syntax
checks for TS-compatible browser code, Windows BAT smoke mode, JSON
persona validation, all unit tests and the preexisting million-record
Atlas stress check.

**Boundaries:** These are concrete, bounded building blocks for the
40-item roadmap. They are not 40 independent new services, semantic
comprehension of all languages, historical truth reconstruction,
million-row vector ANN, autonomous retraining, or guaranteed fast
answers on every PC. Improving those further requires additional
benchmark data and explicit approval for any new paid computation.
