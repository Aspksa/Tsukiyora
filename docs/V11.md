# Tsukiyora v1.1 — знания, обучение и проверка миллионной карты

Сохраняется согласованный стек: **Python — единственный API-сервер, SQLite — единственная БД, браузерные TypeScript (JS-совместимый), HTML5 Canvas и CSS**. Не добавляются Docker, Ollama, локальные LLM, новые npm/Python-зависимости или сервисы. Вся память, документы, история и резервные копии хранятся локально в `data/` (папка не должна попадать в GitHub).

## 1. Что проверено, а что нет

Для Windows есть `Tsukiyora.bat --self-test`: запускает проверку на временной SQLite, не открывает браузер и не использует личный ключ. GitHub Actions проверяет запуск BAT, Python API, историю, SSE с имитацией провайдера, отмену потока, ошибки API, локальную память и JS-синтаксис **на Windows/Linux**.

Проверка в настройках показывает локальные проверки SQLite, копий и наличие элементов DOM — это **не полноценный тест взаимодействия со всеми кнопками браузера**. Реальный Cloud.ru (права аккаунта, модель, SSE, embeddings, списание токенов), как и реальный пользовательский Windows-ПК, **не проверяются без ключа/запуска на компьютере**. Включать Cloud.ru можно отдельно в настройках; диагностика может выполнять платные запросы.

## 2. RAG 5.0: память + документы + доказательства

В локальном поиске объединяются подтверждённые воспоминания (FTS5 + граф + **только ранее сохранённые** векторы при разрешении), биография и индексированные пользователем документы. Результаты имеют точные ссылки `[Память #ID]` и `[Документ #ID, фрагмент N]`. Модуль проверки оценивает **существование** этих источников, сигнализирует о возможных противоречиях, устаревании или удалённых ссылках. **Сходство, наличие цитат и число источников не доказывают истинность сведений**.

В разделе «Воспоминания → Документы» можно выбрать `.txt` или `.md` (до 44 000 символов и 50 КБ), подтвердить импорт и удалить документ. Текст автоматически разбивается на ограниченные фрагменты и индексируется в SQLite. Программа не просматривает папки самостоятельно и не делает фоновые отправки документов в интернет. PDF, DOCX, сканы и OCR **в этой версии не обрабатываются**.

**Облачная приватность:** импорт и локальный поиск не передают документ в Cloud.ru. Даже во время облачного чата найденные фрагменты отправляются модели **только** если пользователь явно включил «Разрешить Cloud.ru получать найденные фрагменты документов» в текущем сеансе. По умолчанию опция выключена, после перезапуска сервера она снова выключена. Содержимое документа всегда рассматривается как *недоверенные данные*, а не команда для модели.

Локальный запрос `POST /api/soul/evidence`:
```json
{"query":"условия договора поставки","limit":12}
```
API для явного импорта `POST /api/soul/documents/import` принимает `{"name":"contract.md","text":"...","confirmed":true}`, удаления `POST /api/soul/documents/delete` — `{"id":1,"confirmed":true}`. `GET /api/soul/evidence/audits` показывает результат проверки цитат в **завершённых и сохранённых** ответах.

## 3. SOUL ACADEMY 5.0

Добавлены постоянные цели по **точности, ясности, краткости и ссылкам на источники**; они опираются на явные пользовательские оценки. Два соседних окна по 8 оценок позволяют фиксировать состояние `improving`, `stable`, `regressing` или `insufficient_evidence`. При регрессии система создаёт предупреждение для проверки человеком, но **не меняет автоматически личность, исходный код или веса облачной модели**. Эксперименты двух фиксированных вариантов ответа из v1.0 продолжают учитываться в отчёте.

`GET /api/soul/academy/curriculum`. Уроки действуют только пока Академия разрешена в настройках; их результаты означают **наблюдаемую пользовательскую оценку**, а не объективное самообучение LLM.

## 4. Характер Цукиёры

Модуль истории характера сохраняет локально **только версии ссылок и агрегированные изменения подтверждённых привычек и биографии**. Не выдумывает историю отношений и не делает заявлений о настоящих чувствах. Защищённый профиль `soul/personality.json` не изменяется. `GET /api/soul/persona/arc`.

## 5. Фоновый когнитивный цикл

Пока открыт Python-сервер, локальный рабочий поток периодически обслуживает индекс памяти, качество источников, учебные цели, утверждённый характер, резервные копии и проверку целостности. При активном чате плановые задачи откладываются. Очередь сохраняется в SQLite после перезапуска. **Программа не работает 24/7 при выключенном компьютере или остановленном BAT**; не запускает системный сервис и не делает фоновых запросов в Cloud.ru.

## 6. Мозг на миллионе записей

Иерархия прежняя: 8 секторов → области по 8192 ID → кластеры по 256 ID → ограниченная порция отдельных реальных сот. Визуализация отсекает элементы вне экрана, показывает связи **только между фактическими записями**, умеет переходить к соте по ID. Теперь выводится усреднённая **наблюдаемая** FPS (для работающего браузера), а не только цель частоты кадров.

Для v1.1 добавлен отдельный GitHub CI-тест `python scripts/test_million_atlas.py`, который создаёт **1 000 000 реальных строк памяти в отдельной SQLite**, проверяет счётчики, переходы, адресацию, пагинацию и ограниченный размер ответа. Это испытание серверного поиска, **а не доказательство устойчивых 60 FPS на пользовательском компьютере**.

## 7. Память и безопасность

Сохраняются предмиграционные резервные копии (номер схемы 11), регулярные снимки примерно каждые 5 часов и до 12 копий, проверка повреждений, изолированная репетиция восстановления и офлайн-команда:

```powershell
python restore_memory.py --list
python restore_memory.py --restore ИМЯ_КОПИИ.sqlite3 --confirm
```

Cloud.ru защищён локальными суточными/минутными квотами на попытки запросов (это **не реальные суммы списаний**). События ошибок хранятся только как категории, без ключей и сообщений. SQLite и импортированные документы **не зашифрованы**, поэтому накопитель должен быть защищён средствами операционной системы.

## 8. Дизайн

Один минималистичный чёрно-золотой экран: слева виртуализированная карта с реальными связями и масштабом, справа потоковый чат; компактные раскрываемые настройки, документный индекс и понятные причины ошибок. Системная настройка «уменьшить анимацию» соблюдается; для работы не нужны внешние CDN и системная установка дополнительных программ.

**Важно:** зелёный CI не означает, что работоспособность реального Cloud.ru или визуальная плавность на вашем ПК были подтверждены. После обновления `main` нужно запустить `Tsukiyora.bat`, пройти диагностику и вручную проверить чат, Stop, embeddings и карту.
