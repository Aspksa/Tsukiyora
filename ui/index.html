            Cognitive Soul 8.0 личность, цели, самостоятельность
            
Цукиёра самостоятельно ведёт только разрешённые локальные цели, дневник и предложения. Личность из soul/personality.json, память и история остаются защищёнными. Её «внутреннее состояние» — программная оценка, а не настоящие эмоции.

            
Загрузка состояния...

            
            
            

              
              
            

            
            
            
            
Cloud.ru, изменения кода, внешние действия, запись фактов в память и активация навыков не входят в разрешения 8.0. Отдельные прежние настройки Cloud.ru не меняются.

            

            

            

            

          

          

            Cognitive Soul 7.0 единый центр развития и доказательных проверок
            
Объединяет прежние источники навыков без копирования памяти, с одной существующей SQLite-очередью. Новые навыки можно одобрить только после 8 уникальных парных контрольных примеров, улучшения минимум на 2 ответа и без регрессий. Сравнения вручную подтверждаются пользователем; это не автоматический тест реальной LLM.

            
Загрузка статуса 7.0…

            

              
            

            

            

            

              Проверить новый навык на эталонных ответах
              
Для каждого независимого контрольного вопроса сравни два уже полученных ответа той же модели при сопоставимых условиях с эталоном. Цукиёра не делает дополнительные платные вызовы. Тексты примеров не сохраняются: в SQLite записываются хеш вопроса и результаты сравнения.

              
              
              
              
              
              
              
              
              
              
              
              
              

                
                
                
              

              

            

            
Изменения кода, памяти, личности, внешние действия и скрытые Cloud.ru-эксперименты не выполняются. Действующий лимит Cloud.ru из Skill Forge 6.0 не повышается.

          

          

            Cognitive Soul 5.0 единый автоматический центр
            
Одна очередь SQLite объединяет локальные циклы версий 1–4: память, проверку источников, обучение, гипотезы и отчёт. Без скрытых Cloud.ru-запросов, переписывания характера и автоматического утверждения стратегий.

            
Загрузка локальной диагностики…

            

              
              
              
            

            
При паузе остаются доступны чат, память и ручные инструменты. Неактивные гипотезы автоматически не утверждаются. Состояние очереди сохраняется после перезапуска.

            

            

            

          

          

            Cognitive Soul 6.0 Autonomous Skill Forge
            

              
              
Включение разрешает не более 1 потенциально платного Cloud.ru-запроса в сутки для создания черновиков. Денежная цена неизвестна. Предлагать готовые навыки Цукиёра будет прямо в чате, применять сама — нет.

            

            
Навыки создаются из подтверждённых положительных оценок и безопасных шаблонов. Локальная проверка оценивает порядок шагов, а не истинное качество LLM. Новые навыки не включаются без отдельного одобрения.

            
Загрузка библиотеки навыков…

            
            
            

              
              
              
            

            
Перенос в другую область и составные навыки формируют только черновики. Для активации нужна проверка и твоё подтверждение.

            
            
            

            

            

            

              Дополнительные ручные настройки бюджета Cloud.ru
              
Бюджет по умолчанию равен нулю. Для будущего облачного конструирования нужны: отдельный запрос бюджета, отдельное одобрение, затем отдельное подтверждение КАЖДОГО платного вызова. Точная стоимость токенов неизвестна; дневной лимит запросов не гарантирует денежного лимита.

              

              
              
              

                
                
                
              

              
Облачный вариант — только черновик из разрешённых шагов, без отправки памяти, документов или исходных диалогов. Согласование бюджета не запускает Cloud.ru.

Локальный когнитивный статус загружается при открытии.

            
            
            

              
              
              
            

            
            
            

              
              
              
            

            
            
            
            

            
            
            
            
            
            
            
            
            
            

            

          

          

            Cognitive Soul 3.0 интеллектуальное самоулучшение
            
Сначала эталоны и безопасная гипотеза, затем тест старой и новой стратегии на одинаковых заданиях. Никаких автоматических платных запросов и внедрений.

            

            
            
            
            
            
            
            
            

            
            
            
            

            
Проверка Cloud.ru платная: ровно 8 попыток на 4 эталонах. Отзывы и оценки сами по себе не доказывают рост интеллекта.

          

          

            Cognitive Soul 4.0 12 направлений саморазвития
            
Генерация 3–5 новых комбинаций методов, развитие навыков по областям, независимые эталоны, сравнение и контроль регрессии. Генерация локальная, испытания с Cloud.ru только вручную.

            
            
            
            
            

            
            
            
            
            
            
            
Для активации нужно 30 разных holdout-заданий на одной модели с улучшением не менее 10 п.п. Запуск партии — максимум 6 пар ответов / 12 запросов; суточный предел — 24 обращения. Фактическую стоимость Cloud.ru система не знает.
